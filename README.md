Fb2GenreSelection (Программа отбора и редактирования жанров FB2)

Fb2GenreSelection — это настольное приложение на C# (.NET Framework 4.8 / Windows Forms), предназначенное для быстрых сканирования, фильтрации, каталогизации и детального парсинга электронных книг формата FB2.

Основные возможности

1. Быстрая фильтрация и навигация
Фильтрация по языку и жанрам: Позволяет отсекать файлы с тегом `ru` или фильтровать книги не на русском языке во всем каталоге.

Двухуровневая выборка: Работа через ComboBox (выбор категорий/жанров, включая спец-разделы «Ошибки» и «Прочие») и чекбоксы быстрых фильтров.

Бесшовная навигация: Отображение каталогов и служебных папок (`..`) на верхних позициях списка с сохранением структуры каталогов.

2. Производительность и оптимизация памяти
Lazy Loading (Ленивая загрузка): При сканировании папок читаются только метаданные, а тяжелый контент загружается только при выборе конкретного файла.

Легковесный кэш: Оптимизированный индекс для каталогов с тысячами файлов (индекс из 3000 файлов занимает ~2.5 МБ RAM).

Мгновенный UI: Переключение категорий и фильтров занимает ~10–15 мс без повторных нагрузок на диск.

3. Детальный парсинг и просмотр файлов FB2
Анализ метаданных: Извлечение названий, серий, номеров в серии, издательских серий и жанров.

Управление авторами: Парсинг списков авторов, соавторов (имя, фамилия, отчество, ID, email).

Извлечение обложек и иллюстраций(`<binary>`): Автоматическое декодирование Base64-данных обложки и расчет её разрешения.

Предпросмотр контента: Генерация HTML-предпросмотра с обложкой, аннотацией (`<annotation>`), историей документа и первыми абзацами текста книги через элемент `WebBrowser`.

Генерация имён файлов: Формирование понятного стандартного имени файла на основе автора, серии и жанра.
